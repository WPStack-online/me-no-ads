## 🌟 Key Features

* **Admin Notice Suppression**: Filters out intrusive plugin upgrade notices, rating prompts, and marketing banners.
* **Security Alert Routing**: Preserves critical core updates and security notices in a dedicated notification drawer.
* **Per-Role Filtering**: Custom rules to keep admin dashboards clean for client accounts while retaining developer alerts.
* **Zero Performance Overhead**: Pure PHP hook filtering without external network calls or database bloat.
